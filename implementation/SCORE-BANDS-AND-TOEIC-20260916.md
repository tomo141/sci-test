# 数値スコアと能力説明の幅を分ける提案

出典：2026-09-16の本人の追加質問「最終どこに落ち着けるのがいい」「TOEICはもっと広い」。観測・記録日：2026-09-16。下記は採択前の提案。70%対応・ラジオ回答・10〜990という採択済み仕様は維持する。

## 今回のおすすめ

数値の範囲は10〜990を保つ。**公開する能力説明を5〜6段階にし、作問・自己評価の人物像はまず7種類に減らす**。19人を50点刻みで並べる前案は比較資料として保存し、本番フォームへ採用しない。表示点の細かさ、能力を説明する区分、実際の測定精度は異なる。

| 用途 | おすすめ |
|---|---|
| 内部の難度と能力 | 連続したa・b・c・θと不確かさを保存。整数や50刻みに丸めて学習しない |
| 作問時の初期難度 | 7人の具体的な基準人物から、約7割正解しそうな段階を選ぶ。自信は任意ラジオ。難度帯は広めの事前情報として扱う |
| 回答者の自己評価 | 同じ7段階の問題を「10問中7問くらい解けそう」という自認。本人の学歴を申告したことにはしない |
| 結果の点数 | 数値を残し、問題数と参考幅を併記。1点・5点差を成長や順位差の確証として説明しない |
| 公開する能力説明 | 5〜6段階の「何が分かるか」を主役にし、教育段階は補足。150〜200点前後の帯から検討し、実測・内容審査で境界を決める |

7人の案：小学校修了直後／中学校修了直後／高校の該当理科等を履修した直後／大学2年の該当専門基礎を履修した直後／該当分野の学士取得直後／該当分野の修士取得直後／該当分野の博士を取得し現在も直接関わる研究をしている人。独学者も自分と近い知識段階を選べる。

7人の順序や間隔も、実測した絶対的な序列ではない。人物像を同じ間隔の点数へ強制配置しない。最初は大まかな事前分布を置き、基準問題と実回答で対応を更新する。特に修士・博士の差は大分野の広さより小分野の専門性に表れやすい可能性があり、大分野と小分野を分けて検証する。

公開の説明例：身近な科学の基本／中高の主要概念／大学入門の体系／専門科目の標準知識／高度な専門知識。これは名称案で、まだ数値との対応を検証していない。先に「800点は修士」と断言して数字を合わせない。**総合は10分野の合計で、ある1分野の学位への対応は定義しない**。

## なぜTOEICの説明は広いのか

TOEIC L&Rは各セクション5〜495の5点刻みだが、IIBCのScore Descriptorはリスニング3区分、リーディング4区分で典型的な強み・弱みを説明している。段階の数は、数値の刻みとは別。

ETSのガイドでは、各セクションの測定標準誤差（SEM）は約25点。5点差を安定して識別できるという意味ではない。一方、公式資料が能力表の帯幅をSEMだけから決めたとまでは確認できない。「典型的に何ができるか」を理解しやすい単位で示すという表示目的も考えて設計する。通常のスコア刻みが細かいことには、継続的な成長の記録や集計に使えるという利点があるが、細かい刻み自体が精度を増やすわけではない。

## TOEICはデータだけで問題の点数を決めるのか

通常のTOEIC L&Rについて、ETSは**セクションごとの正答数を5〜495の尺度へ換算する**と説明している。「この難問は10点、この易問は1点」という個別配点を積み上げる説明ではない。試験回ごとの難易度差は共通問題等を用いた等化で調整する。IPオンラインや別製品の適応方式まで同じ実装と断定しない。

作問は内部・外部の担当者による素案から始まり、組み立て・複数のレビュー・回答データの分析が続く。2016年更新のETS研究報告にも、内容と統計の仕様に基づく構成、パイロット実施、問題の難度・識別・公平性の分析が記載されている。したがって大量の正誤データだけで良問や測定内容が自動的に決まるわけではない。ただし「作問者が各問題に700点向けなどの対象レベルをどう指定するか」という内部の具体的指示までは、今回確認した公開資料で分からない。

全分野科学検定では人により問題が異なるため、単なる正答数換算ではなく、問題特性に応じた回答の尤度から推定する方式を続ける。内容の範囲・正解の妥当性・出典は人が審査し、実回答が難度見積もりを補正する。

## 段階を細かくする条件

最初から帯を狭くせず、能力説明の違いが代表問題で確認できること、作問者同士で区別できること、別データでも予測が良くなること、再受験や問題入替で段階が過度に揺れないことを確認する。境界付近は隣接段階にまたがる表現にする。測定幅が複数段階をまたぐ腕試しでは、単一の学習段階を断定しない。

50問の総合試験は1分野5問、100問でも10問。総合点の情報量と、その内訳10分野の情報量は同じではない。分野別には追加20問・将来の分野本試験を案内できる。TOEIC各セクション100問の誤差を、この検定の各分野へそのまま流用しない。
