# 腕試しの正答率フィードバックと受験後アンケート

記録日：2026-09-19 JST。出典：この作業タスクでの本人の明示依頼、現行コード、下記のローカル検証。本人の受験結果の本文は Git 対象外のローカル記録に保存する。

## 採択

- 腕試しは予測正答率75〜85%から開始する。今回の正答率が狙いより低ければ高い予測正答率を、高ければ低い予測正答率を狙う。
- 分野配分・未見優先を保つ。範囲内の候補がない場合、その範囲で易しい側を優先する。
- 感想は難易度・回答テンポの2項目と任意の自由記述。問題文の長さの設問は設けない。
- 分野ごとの自己評価も聞く。「各グループが約70%正解できる問題を、自分も10問中7問くらい解けそうか」に一番近いグループを選ぶ。

## 出題の実装

新規腕試しは `exam-v5-trial-feedback` / `trial-fluency-v2-feedback` を保存する。旧 `trial-fluency-v1` やさらに古い受験は再開しても元の選び方を維持する。本試験の選択・採点は変更しない。

今回の採点対象回答を n 問、その正解を k 問として、目標帯の移動量を次で計算する。

```text
移動量 = clamp(0.5 × (0.8 × n − k) / (n + 8), −0.10, +0.10)
次問の目標帯 = [0.75 + 移動量, 0.85 + 移動量]
```

基準の中心は80%。動いた目標自体を次の達成目標にすると過剰な追従が起きるため、現在の正答率は基準の80%と比較する。8問相当の緩和と0.5倍の調整で、序盤の偶然の正誤による急変を抑える。境界は小数第4位で保存する。係数・緩和量・最大移動幅は初期の実装値であり、本人が個別に指定した数値や実測で最適化済みの値ではない。

| 今回ここまでの回答 | 次問の目標帯 |
|---|---|
| 開始時 | 75〜85% |
| 10問中6問正解 | 約81〜91% |
| 10問中8問正解 | 75〜85% |
| 10問中9問正解 | 約72〜82% |

選ぶ順序：10分野の配分 → 未見、足りなければ既出回数が最少の問題 → 目標帯の短問 → 帯内の他の問題 → 易しい側で帯に近い問題 → 易しい候補もなければ難しい側で帯に近い問題。情報量・重点群・探索の抽選は、この候補集合の中で行う。

過去の回答は従来どおり腕試しの実力推定に同じ重みで用いる。ただし、今回の正答率フィードバックと今回の採点には入れない。問題の a・b・c、70%の難度対応、総合10〜990・分野1〜99、即時解説、キー操作は変えない。

選択理由にはその時点の目標帯、今回の正解数・回答数、易しい側への代替使用を保存する。[運営集計](operations/observe-trial-fluency.sql)は移動後の目標帯を読んで集計し、旧版の75〜85%と取り違えない。目標の記録が欠けた回答を帯内・帯外の分母へ入れない。

## アンケートと自己評価

腕試し・総合本試験の結果ページに任意の入口を置く。結果閲覧、共有、次の受験を先に使える。感想を送る場合は難易度5択・回答テンポ4択の2項目を選び、自由記述は空欄可・2,000文字以内とする。

感想は本人の受験に結び付け、既存の非公開 `science_events` に1受験1件で保存する。再送は二重登録しない。得点、出題版、採点版、問題バンク、50/100問などの条件はサーバー側で記録する。管理者だけが20件ずつ読み出せる。ブラウザからは自由なユーザーID・得点・条件を登録できない。案内メールへの同意とは別で、点数・難度・信頼スコアには自動反映しない。

自己評価は感想のすぐ下に、既存の7グループから1分野ずつ回答する入口を置く。大分野全体・小分野を区別し、修士・博士は選んだ分野の専門と明示する。「まだ判断できない」も選べる。既存の非公開 `science_level_assessments` を使い、学位の保有を確認したデータとは扱わない。大分野から小分野への自動転記、自己評価から得点や b への直接の換算はしない。

[感想の集計SQL](operations/observe-experience-survey.sql)は回答した人だけの集計であり、全受験者の代表値ではない。自由記述・個人識別子を集計に含めず、出題版・問題バンク・採点版・試験の長さを分ける。

ローカルの[20問試用](short-questions/adaptive.html)にも2項目と自己評価を接続した。ローカル版はブラウザ内に保存し、本番へ送信しない。バンクのハッシュ・保存キーを保ち、前の20問の回答・スコアを残す。「もう20問」で次に始めた受験から新方針になる。自己評価は大分野と小分野ごとに保存する。

## b の校正との関係

今回のフィードバックは、未校正の時期でも回答体験を調整するための仕組み。予測確率が正しいことや最終正答率80%を保証しない。分野差、能力推定の誤差、仮難度の誤差、候補不足、偶然が残る。

ローカル試用は b を学習していない。アプリの校正も、対象外の同分野回答8問以上から実力を推定できた独立の回答が問題ごとに200件以上あり、実力帯の偏り・別データでの予測改善などの条件を満たして初めて採用候補になる。少人数の感想だけで自動補正されるものではない。初期テスターの回答と感想で要確認問題を絞り、内容と仮難度を点検する。人物像と点数帯の境界は引き続き未検証。
