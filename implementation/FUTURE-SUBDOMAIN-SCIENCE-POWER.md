# 小分野受験の解放時に検討する「全分野科学力」

出典：この改装タスクでのともよしさんの発言。観測日・記録日：2026-09-15（JST）。
状態：本人から記憶を依頼された将来の実装アイデア。実装・公開は未実施。
適用を検討する時期：小分野受験を解放するとき。

## 本人の案

> 総合スコア、大分野スコア1位分野、大分野スコア2位分野、大分野スコア3位分野、小分野スコア1位分野、小分野スコア2位分野、をレーダーチャートに表示して、すべての平均を5の倍数で丸めたスコアを全分野科学力と定義するのがよさそう。小分野受験を解放したときに実装するアイデアとして覚えておいて。

レーダーチャートは次の6軸で構成する。

1. 総合スコア
2. 大分野スコアが1位の分野
3. 大分野スコアが2位の分野
4. 大分野スコアが3位の分野
5. 小分野スコアが1位の分野
6. 小分野スコアが2位の分野

上位分野は、本人の分野別スコアの中で高い順と解釈して記録する。各軸には該当する分野名と点数を表示する。

「全分野科学力」は6軸の等重みの平均を5の倍数へ丸めた指標とする案。尺度をそろえた軸の値をS、D₁、D₂、D₃、s₁、s₂、丸めをR₅と書くと、式の候補は次のとおり。

`全分野科学力 = R₅((S + D₁ + D₂ + D₃ + s₁ + s₂) / 6)`

## 実装時に決める事項

- **各軸の尺度**：現在の新版は総合が0〜1000、大分野が0〜100。生の数値をそのまま平均すると総合だけの寄与が大きくなる。全軸を0〜100か0〜1000など同じ尺度にそろえる方式を決める。今回、換算方式まで本人が指定したわけではない。
- **スコアの時点と条件**：今回の受験、現在の推定、自己ベストのどれを使うかをそろえる。推定精度や必要回答数、未受験の軸、同点時の分野選択を定義する。未取得を0に置き換えたり、欠けた軸を黙って平均から外したりしない。
- **丸めの規則**：最も近い5の倍数へ丸める案を出発点とし、ちょうど中間の値の扱いなどを確定する。元の推定値と計算式の版は保持する。
- **指標の位置付けと表示**：総合・大分野・小分野には同じ回答の影響が重なる。得意分野も表す新指標として測定上の意味と見せ方を確認する。総合スコア、過去の結果やランキングの扱いを変更する場合は、その範囲と版の切替を別途定義する。
