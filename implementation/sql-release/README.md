2. `followup-schema-0020-0028.sql`：前段のハッシュ台帳を確認した後の追加変更。

`manifest.json` のSHA-256はローカル検証版の値。ブラウザへ転記する場合は、エディターの全選択・コピーで読み戻した全文との一致を実行前に確認する。アクセシビリティ表示の省略箇所だけで一致を判断しない。実行後はRESTでハッシュ台帳と旧データ保持を照合する。
