# レベル定義（正本）

正本ファイル: `skills/science-question-level-calibrator/SKILL.md`

本検定の `difficulty_initial` は **「そのレベルの基準集団が50%正答する」** 内容かどうかで決める。
TOEIC型スケールや想定正答率の機械的対応表は使わない。

## 800/900 の深さ基準

### 800 にふさわしい例（既存バンクより）

- 化学: DFT ホーエンベルク・コーン定理
- 物理: ハイゼンベルク不確定性原理（ΔxΔp ≥ ℏ/2）
- 工学: 転位による塑性変形の機構
- 医歯薬: MHC クラスI 抗原提示経路
- 人文: ケルゼン「根本規範」

### 800 にふさわしくない例

- 熱力学第二法則のエントロピー増大（→ 400〜500）
- 根粒菌・窒素固定の基本（→ 300〜400）
- 確証バイアスの用語再認（→ 400〜600）

### 900 にふさわしい例

- 化学: フロンティア軌道理論と芳香族求電子置換
- 生物: ラクトースオペロンの cAMP-CRP 制御
- 地学: チャンドラセカール限界
- 医歯薬: BCR-ABL / イマチニブ適応疾患

### 900 にふさわしくない例

- lim(1+1/n)ⁿ = e（→ 400〜500）
- P vs NP 未解決の再認（→ 600〜700）
- CRISPR の gRNA+Cas9 基本構造（→ 500〜600）

## よくある誤り

| 誤り | 正しい見方 |
|------|-----------|
| 大学用語を入れたら600+ | 内容の深さと専門一致基準で判断 |
| 有名人物・用語を700+ | 内容が中学〜高校なら300以下 |
| 800/900 をバランス用に機械配置 | 内容が届かなければ付けない |
| TOEIC帯5 = 900 | 本検定では無関係 |
